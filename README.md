## 2. Иерархия клиентов

Каждый клиент относится к группе компаний — ЦПР.

Каждый ЦПР относится к отрасли — КП.

Схема:

```text
Клиент
  └── ЦПР
       └── КП / отрасль
```

Связи:

```text
clients.client_id  -> monthly_client.client_id
clients.client_id  -> daily_balances.client_id
clients.client_id  -> transactions.client_id
clients.client_id  -> accounts.client_id
clients.client_id  -> credit_products.client_id

clients.cpr_id     -> cpr.cpr_id
cpr.kp_id          -> kp.kp_id
```

В таблице `monthly_client` поля `cpr_id` и `kp_id` продублированы.

## 6. Файл `accounts.csv`

Файл содержит счета клиентов.

|---|---|
| `client_id` | идентификатор клиента |

| `currency` | валюта |

| Тип | Описание |
|---|---|

| `NSO_FIX_180` | НСО на 180 дней |

| `NSO_FLOAT` | НСО с плавающей ставкой |

## 16. Форматы данных

### Даты

Даты передаются в формате:

```text
YYYY-MM-DD
```

Пример:

```text
2025-03-31
```

---

### Суммы

Все суммы указаны в рублях, если для конкретного поля не указано иное.

---

### Флаги

Флаговые поля принимают значения:

```text
0
1
```

---

### Пропуски

Пропуски встречаются в полях, где значение может отсутствовать по смыслу.

Примеры:

- `close_date` у активных счетов и продуктов;
- `avg_rate` при отсутствии НСО;
- `churn_next_month` для последнего месяца;
- поля НСО у клиентов без открытых НСО.
